# Privacy policy

## Search Tabs for Zammad

Effective date: 28 October 2026. Publisher: Eugene Bachura. Contact: [eugene.bachura@gmail.com](mailto:eugene.bachura@gmail.com).

This independent Chrome extension keeps multiple search queries as tabs in the classic Zammad interface and helps users compose search filters.

## Information handled

On sites that you explicitly enable, the extension reads the current search query, Zammad account ID, interface language and state, priority and group labels needed by its filter builder. Search queries can contain names, email addresses, ticket references, or other personal and confidential information that you enter.

The extension reads the existing page's task navigation and native dialog markup to display its controls. It does not read ticket conversations or attachments to build these controls. Search results continue to be provided by your Zammad installation.

## Storage and purpose

Search text is stored in Chrome's local extension storage on your device. Entries are grouped by Zammad origin, application path and account ID so searches can be restored and separated between accounts. The list of sites where you enable the integration is also stored locally. Site access grants are managed by Chrome. Filter choices and unfinished drafts are held in memory while the page is open.

Data is used only to provide search tabs and the filter builder. The extension's use of information complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.

## Sharing and network activity

The extension does not send data to the publisher or third parties. It has no analytics, advertising, tracking, remote code, cloud backup or Chrome storage synchronization. The publisher cannot access your saved queries.

Running a search uses the Zammad page you already opened. That page communicates with your chosen Zammad server under its own privacy and security rules. The extension also reuses that page's native styles and icons. The extension does not create an additional destination for your queries.

## Retention and removal

Saved queries remain in your Chrome profile until you close their search tabs, remove saved data through the extension's settings, or uninstall the extension. Signing out hides your searches but does not erase them. Revoking site access through Chrome prevents further page access and does not itself erase previously saved queries.

Choose "Disable on this site" in the toolbar panel to stop the integration on that site while keeping its saved queries. To remove all saved queries, open Settings and choose "Disable all sites and remove saved searches". The extension disables its integration and asks Chrome to revoke optional site access. If Chrome cannot remove that access, the panel explains how to remove it in Chrome settings; the integration remains disabled. These actions do not delete tickets or other information held by your Zammad server.

## Security

Saved queries are local browser-profile data, not an encrypted vault. People or software with access to your Chrome profile or device may be able to read them. The extension does not request passwords, authentication cookies, payment details or browser history.
